SQL
SQL = Structured Query Language
SQL (Structured Query Language) is used to store, retrieve, update, and delete data from a database.
With SQL, we can:
Create databases
Create tables
Insert data
Read data
Update data
Delete data
Search/filter data


What is a Database
A database is an organized collection of data.

DBMS = Database Management System
A DBMS is software used to create, store, manage and retrieve data.
Examples:
PostgreSQL
MySQL
Oracle Database
Microsoft SQL Server
SQLite

RDBMS
RDBMS = Relational Database Management System
It stores data in the form of tables and allows relationships between tables

| Relational                           | Non-Relational                                          |
| ------------------------------------ | ------------------------------------------------------- |
| Data stored in tables                | Data can be documents, key-value, graphs, etc.          |
| Uses rows and columns                | Flexible structure                                      |
| Fixed/schema-based structure         | Usually more flexible schema                            |
| Uses SQL                             | Often uses database-specific query methods              |
| Primary & Foreign Keys commonly used | Relationships handled differently                       |
| Good for structured data             | Good for flexible/unstructured or rapidly changing data |
| MySQL, PostgreSQL, Oracle            | MongoDB, Redis, Cassandra                               |

# SQL Data Types
A data type defines what kind of value a column can store in a database.

1. Numeric Data Types

| Data Type      | Use                          | Example      |
| -------------- | ---------------------------- | ------------ |
| `INT`          | Whole numbers                | `25`         |
| `BIGINT`       | Very large whole numbers     | `9876543210` |
| `FLOAT`        | Decimal numbers              | `25.5`       |
| `DOUBLE`       | More precise decimal numbers | `25.5678`    |
| `DECIMAL(p,s)` | Exact decimal values         | `9999.99`    |

2. String / Character Data Types

| Data Type    | Use                  | Example                 |
| ------------ | -------------------- | ----------------------- |
| `CHAR(n)`    | Fixed-length text    | `'ABC'`                 |
| `VARCHAR(n)` | Variable-length text | `'Pallavi'`             |
| `TEXT`       | Large amount of text | `'Long description...'` |

3. Date and Time

| Data Type   | Use                                       | Example                 |
| ----------- | ----------------------------------------- | ----------------------- |
| `DATE`      | Date                                      | `'2026-08-11'`          |
| `TIME`      | Time                                      | `'14:30:00'`            |
| `DATETIME`  | Date + time                               | `'2026-08-11 14:30:00'` |
| `TIMESTAMP` | Date + time, commonly used for timestamps | `'2026-08-11 14:30:00'` |

4. Boolean
BOOLEAN stores a true/false value.
is_active BOOLEAN

Example:
INSERT INTO student
VALUES (1, 'Pallavi', TRUE);

#importent to remember:

DECIMAL      → Exact decimal number
FLOAT        → Decimal number
DATE         → Date

DATETIME     → Date + time
BOOLEAN      → TRUE / FALSE

SQL Operators – Notes

Operators are symbols or keywords used to perform operations or comparisons in SQL.

1. Arithmetic Operators

Used for mathematical calculations.

| Operator | Meaning             | Example     |
| -------- | ------------------- | ----------- |
| `+`      | Addition            | `marks + 5` |
| `-`      | Subtraction         | `marks - 5` |
| `*`      | Multiplication      | `fees * 2`  |
| `/`      | Division            | `fees / 2`  |
| `%`      | Modulus / remainder | `marks % 2` |

Example:
SELECT marks + 5 FROM student;
___________________________________

2. Comparison Operators
Used to compare two values.

| Operator | Meaning                  |
| -------- | ------------------------ |
| `=`      | Equal to                 |
| `<>`     | Not equal to             |
| `!=`     | Not equal to             |
| `>`      | Greater than             |
| `<`      | Less than                |
| `>=`     | Greater than or equal to |
| `<=`     | Less than or equal to    |


Examples:
SELECT * FROM student WHERE marks > 80;
SELECT * FROM student WHERE city = 'Pune';
SELECT * FROM student WHERE age >= 20;
SELECT * FROM student WHERE city <> 'Pune';
_________________________________________________________________________

3. Logical Operators
Used to combine or reverse conditions.

AND
Both conditions must be true.
SELECT * FROM student WHERE city = 'Pune' AND marks > 80;

OR
At least one condition must be true.
SELECT * FROM student WHERE city = 'Pune' OR city = 'Nashik';

NOT
Reverses the condition.
SELECT * FROM student WHERE NOT city = 'Pune';

4. Special Operators
BETWEEN
Checks whether a value is within a range.
SELECT * FROM student WHERE marks BETWEEN 60 AND 90;

IN
Checks whether a value matches any value in a list.
SELECT * FROM student WHERE city IN ('Pune','Nashik','Mumbai');

NOT IN
Excludes specified values.
SELECT * FROM student WHERE city NOT IN ('Pune','Nashik');

LIKE
Used for pattern matching.
SELECT * FROM student WHERE name LIKE 'R%';
R% → starts with R.

SELECT * FROM student WHERE name LIKE '%a';
%a → ends with a.

IS NULL
Checks for NULL values.
SELECT * FROM student WHERE city IS NULL;

IS NOT NULL
Checks for non-NULL values.
SELECT * FROM student WHERE city IS NOT NULL;

************************* Constraints ***********************

# Constraints are rules defined on columns in a database table to ensure data accuracy, validity, and integrity.
# The main constraints are PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE, DEFAULT, and CHECK.
| Constraint    | Purpose                               |
| ------------- | ------------------------------------- |
| `PRIMARY KEY` | Uniquely identifies each row          |
| `FOREIGN KEY` | Creates a relationship between tables |
| `NOT NULL`    | Prevents empty/NULL values            |
| `UNIQUE`      | Prevents duplicate values             |
| `DEFAULT`     | Provides a default value              |
| `CHECK`       | Restricts values based on a condition |

1. PRIMARY KEY
Uniquely identifies every record.id cannot be duplicate or NULL.

CREATE TABLE student (
    id INT PRIMARY KEY,
    name VARCHAR(30)
);

2. FOREIGN KEY
Connects one table to another table.Here, employee.d_id is the Foreign Key.

CREATE TABLE department (
    d_id INT PRIMARY KEY,
    d_name VARCHAR(30)
);

CREATE TABLE employee (
    e_id INT PRIMARY KEY,
    e_name VARCHAR(30),
    d_id INT,
    FOREIGN KEY (d_id) REFERENCES department(d_id)
);


3. NOT NULL
Does not allow NULL.

CREATE TABLE student (
    id INT PRIMARY KEY,
    name VARCHAR(30) NOT NULL
);

This is invalid:
INSERT INTO student VALUES (1, NULL);


4. UNIQUE
Does not allow duplicate values.Two students cannot have the same email.

CREATE TABLE student (
    id INT PRIMARY KEY,
    email VARCHAR(50) UNIQUE
);

5. DEFAULT
Automatically gives a value if you don't provide one.

CREATE TABLE employee (
    id INT PRIMARY KEY,
    name VARCHAR(30),
    city VARCHAR(20) DEFAULT 'Nashik'
);

If you insert:

INSERT INTO employee (id, name)
VALUES (1, 'Pallavi');

city automatically becomes:
Nashik


6. CHECK
Allows only values that satisfy a condition.

CREATE TABLE student (
    id INT PRIMARY KEY,
    name VARCHAR(30),
    age INT CHECK (age >= 18)
);

This is invalid:because age must be 18 or above.

INSERT INTO student
VALUES (1, 'Pallavi', 15);


****************  Referential integrity  *************************
Referential integrity
Definition
Referential integrity is a rule that ensures relationships between tables remain valid and consistent.
It means a Foreign Key value must either match an existing value in the referenced 
table or be NULL (if NULL is allowed).
Referential integrity prevents invalid or orphan records and keeps relationships between tables consistent.

Remember:
Primary Key → Parent table
Foreign Key → Child table
Referential Integrity → Keeps their relationship valid.

# Aggregate functions

Aggregate functions are built-in SQL functions that perform calculations on multiple rows and return one result.
| Function  | Meaning             | Example       |
| --------- | ------------------- | ------------- |
| `COUNT()` | Counts rows/values  | `COUNT(*)`    |
| `SUM()`   | Calculates total    | `SUM(salary)` |
| `AVG()`   | Calculates average  | `AVG(salary)` |
| `MIN()`   | Finds minimum value | `MIN(salary)` |
| `MAX()`   | Finds maximum value | `MAX(salary)` |

2. COUNT()
COUNT() is used to count rows or non-NULL values.

Syntax
SELECT COUNT(column_name)
FROM table_name;

Example
SELECT COUNT(*)
FROM employees;

--------------------------------------------------------------
3. SUM()
SUM() calculates the total of a numeric column.

Syntax
SELECT SUM(column_name)
FROM table_name;

Example
SELECT SUM(salary)
FROM employees;

--------------------------------------------------------------

4. AVG()
AVG() calculates the average of numeric values.

Syntax
SELECT AVG(column_name)
FROM table_name;

Example
SELECT AVG(salary)
FROM employees;

--------------------------------------------------------------

5. MIN()
MIN() returns the smallest value.

Syntax
SELECT MIN(column_name)
FROM table_name;

Example
SELECT MIN(salary)
FROM employees;

---------------------------------------------------------------

6. MAX()
MAX() returns the largest value.

Syntax
SELECT MAX(column_name)
FROM table_name;

Example
SELECT MAX(salary)
FROM employees;
----------------------------------------------------------------
6. Aggregate Functions with GROUP BY
GROUP BY creates groups, and aggregate functions calculate a result for each group.

Example
Find total salary department-wise:

SELECT department, SUM(salary)
FROM employees
GROUP BY department;
----------------------------------------------------------------
11. GROUP BY with MIN()
Find minimum salary in each department:

SELECT department, MIN(salary)
FROM employees
GROUP BY department;
----------------------------------------------------------------
12. GROUP BY with MAX()
Find maximum salary in each department:

SELECT department, MAX(salary)
FROM employees
GROUP BY department;
----------------------------------------------------------------
13. WHERE + GROUP BY + HAVING
These can be used together.

SELECT department, AVG(salary)
FROM employees
WHERE salary > 30000
GROUP BY department
HAVING AVG(salary) > 40000;

******** SQL Clauses *********
A clause is a part of an SQL query that performs a specific operation, such as filtering, grouping, or sorting data.
-----------------------------------------------------------------------------------------------------------------------
1. WHERE Clause
Used to filter rows based on a condition.

SELECT * FROM student WHERE city = 'Pune';

Other examples:

SELECT * FROM student WHERE marks > 80;
SELECT * FROM student WHERE age >= 20;
SELECT * FROM student WHERE city <> 'Pune';

Interview definition:
WHERE filters individual rows before grouping.
___________________________________________________________________________________________________________________________
2. DISTINCT Clause
Used to return unique values and remove duplicates.

Syntax : SELECT DISTINCT column_name FROM table_name;
SELECT DISTINCT city FROM student;
________________________________________________________________________________________________________________________________
3. ORDER BY Clause
Used to sort the result.

Syntax : SELECT * FROM table_name ORDER BY column_name ASC;

Ascending
SELECT * FROM student ORDER BY marks ASC;

Descending
SELECT * FROM student ORDER BY marks DESC;

ASC = Ascending
DESC = Descending
_______________________________________________________________________________________________________________________________

4. GROUP BY Clause
Used to group rows having the same values.
Usually used with aggregate functions like COUNT(), SUM(), AVG(), MAX(), and MIN().

Syntax : SELECT column_name, COUNT(*)
FROM table_name
GROUP BY column_name;

SELECT city, COUNT(city)
FROM student
GROUP BY city;

Example:-
Pune     3
Nashik   2
Mumbai   1
_______________________________________________________________________________________________________________________________
5 . LIMIT Clause
The LIMIT clause is used to restrict the number of rows returned by a query.
It is commonly used with SELECT.
LIMIT is useful when you don't want to retrieve the entire table.

Syntax
SELECT column_name     
FROM table_name
WHERE condition
ORDER BY column DESC
LIMIT number;

Restricts the number of records.

SELECT *
FROM employees
LIMIT 3;
Together
SELECT *
FROM employees
ORDER BY salary DESC
LIMIT 3;

Meaning:
Sort employees from highest salary to lowest and return only the top 3.
_______________________________________________________________________________________________________________________________
6 . OFFSET Clause 
OFFSET is used to skip a specified number of rows before returning the remaining rows.
It is commonly used with LIMIT.

Simple meaning
LIMIT = How many rows to take
OFFSET = How many rows to skip

Syntax:
SELECT *
FROM table_name
LIMIT number_of_rows OFFSET number_of_rows_to_skip;

Example:
SELECT *
FROM employees
LIMIT 3 OFFSET 2;

Meaning:
Skip the first 2 rows
Return the next 3 rows
_______________________________________________________________________________________________________________________________
7. WHERE Clause
Used to filter records based on a condition.

Syntax:
SELECT * FROM table_name
WHERE condition;

Example:
SELECT * FROM employee
WHERE salary > 30000;
_______________________________________________________________________________________________________________________________
8. BETWEEN Operator
Used to select values within a range, including both boundary values.

Syntax:
SELECT * FROM table_name
WHERE column_name BETWEEN value1 AND value2;

Example:
SELECT * FROM employee
WHERE salary BETWEEN 30000 AND 50000;

This includes 30000 and 50000.
_______________________________________________________________________________________________________________________________
9. IN Operator
Used to match a column with multiple possible values.

We can write:
SELECT * FROM employee
WHERE city IN ('Pune', 'Nashik', 'Mumbai');
NOT IN
SELECT * FROM employee
WHERE city NOT IN ('Pune', 'Nashik');
_______________________________________________________________________________________________________________________________
10. LIKE Operator
Used for pattern matching with text.

% — Zero or more characters
SELECT * FROM employee
WHERE name LIKE 'P%';

Means name starts with P.

Examples:

LIKE 'P%'     -- starts with P
LIKE '%a'     -- ends with a
LIKE '%all%'  -- contains "all"
_ — Exactly one character
SELECT * FROM employee
WHERE name LIKE 'P_llavi';

_ represents one character.
_______________________________________________________________________________________________________________________________
11. UPDATE Statement
Used to modify existing records.

Syntax:
UPDATE table_name
SET column_name = new_value
WHERE condition;

Example:
UPDATE employee
SET salary = 40000
WHERE id = 101;

⚠️ Important: Always use WHERE unless you intentionally want to update every row.

UPDATE employee
SET salary = 40000;

This updates the salary of all employees.
_______________________________________________________________________________________________________________________________
12. DELETE Statement
Used to delete existing records.

Syntax:
DELETE FROM table_name
WHERE condition;

Example:
DELETE FROM employee
WHERE id = 101;

⚠️ Without WHERE:
DELETE FROM employee;
This deletes all rows from the table.

JOIN in SQL
A JOIN is used to combine data from two or more tables using a related column.

For example, if we have:
department

d_id	d_name
1	Computer
2	Electrical
3	Mechanical

employee

e_id	e_name	salary	d_id
101	Rahul	30000	1
102	Priya	35000	2
103	Amit	28000	1

Here, d_id is the common/related column.
-----------------------------------------------------------------------------------------------------------------------------
1 ] INNER JOIN in SQL

INNER JOIN is used to combine rows from two or more tables based on a related column.

👉 It returns only the matching records from both tables.

Syntax
SELECT columns
FROM table1
INNER JOIN table2
ON table1.column = table2.column;

SELECT employee.e_id, employee.e_name, department.d_name
FROM employee
INNER JOIN department
ON employee.d_id = department.d_id;
------------------------------------------------------------------------------------------------------------------------------
2 ] LEFT JOIN in SQL

LEFT JOIN returns all records from the left table and the matching records from the right table.

If there is no matching record in the right table, it returns NULL.

Syntax
SELECT columns
FROM table1
LEFT JOIN table2
ON table1.column = table2.column;

SELECT employee.e_name, department.d_name
FROM employee
LEFT JOIN department
ON employee.d_id = department.d_id;
------------------------------------------------------------------------------------------------------------------------------
3 ] RIGHT JOIN 
returns all records from the right table and only the matching records from the left table.

If there is no matching record in the left table, it returns NULL.

Syntax
SELECT columns
FROM table1
RIGHT JOIN table2
ON table1.column = table2.column;

SELECT employee.e_name, department.d_name
FROM employee
RIGHT JOIN department
ON employee.d_id = department.d_id;
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------
4] FULL OUTER JOIN

Returns:
All matching records
All non-matching records from the left table
All non-matching records from the right table

SELECT *
FROM employee
FULL OUTER JOIN department
ON employee.d_id = department.d_id;

SELECT *
FROM table1
LEFT JOIN table2
ON table1.column = table2.column
UNION
SELECT *
FROM table1
RIGHT JOIN table2
ON table1.column = table2.column;

Example :
SELECT employee.e_name, department.d_name
FROM employee
LEFT JOIN department
ON employee.d_id = department.d_id
UNION
SELECT employee.e_name, department.d_name
FROM employee
RIGHT JOIN department
ON employee.d_id = department.d_id;

##################### VIEW ####################

Definition:
A VIEW is a virtual table created from the result of a SQL query. It does not normally store the actual data separately; it stores the query definition.

Syntax:

CREATE VIEW view_name AS
SELECT column1, column2
FROM table_name
WHERE condition;

CREATE VIEW course_details AS
SELECT intern_id, intern_name, email, phone, course
FROM interns
WHERE course = 'Python';
--------------------------------------------------------------------
##########################   INDEX   ############################

Definition:
An INDEX is a database object that helps SQL find rows faster, similar to an index in a book.

Syntax:
CREATE INDEX index_name
ON table_name(column_name);

Example:
CREATE INDEX idx_emp_name
ON employe(emp_name);

Now searches using emp_name can be faster:

SELECT *
FROM employe
WHERE emp_name = 'Pallavi Hujare';

Remove an index in MySQL:
DROP INDEX idx_emp_name ON employe;
-------------------------------------------------------------------------------
| VIEW                         | INDEX                                        |
| ---------------------------- | -------------------------------------------- |
| Virtual table                | Search optimization structure                |
| Stores query definition      | Stores indexed data references               |
| Used for simplicity/security | Used mainly for speed                        |
| Accessed using `SELECT`      | Automatically used by the database optimizer |
| `CREATE VIEW`                | `CREATE INDEX`                               |
-------------------------------------------------------------------------------

#################### SQL Commands  #######################

SQL commands are mainly divided into 5 categories:

1. DDL — Data Definition Language
Used to create and change database structure.

Command	        Use
CREATE	       Create database/table/view/index
ALTER	       Modify table structure
DROP	       Delete table/database
TRUNCATE   	   Remove all rows

----------------------------------------------------
2. DML — Data Manipulation Language
Used to modify data inside tables.

Command	        Use
INSERT     	Add data
UPDATE	    Modify data
DELETE  	Remove data
INSERT      INTO student VALUES (1, 'Pallavi', 20);


UPDATE student
SET age = 21
WHERE id = 1;


DELETE FROM student
WHERE id = 1;
-----------------------------------------------------
3. DQL — Data Query Language
Used to retrieve data.

Command	    Use
SELECT  	Fetch data

SELECT * FROM student;
SELECT name, age
FROM student
WHERE age > 18;

Common SELECT clauses:
WHERE
GROUP BY
HAVING
ORDER BY
LIMIT
OFFSET
DISTINCT
-----------------------------------------------------
4. DCL — Data Control Language
Used to control user permissions.

Command	        Use
GRANT	    Give permissions
REVOKE	    Remove permissions


GRANT SELECT ON student TO user1;

REVOKE SELECT ON student FROM user1;
----------------------------------------------------
5. TCL — Transaction Control Language
Used to manage transactions.

Command     	Use
COMMIT	     Permanently save changes
ROLLBACK	    Undo changes
SAVEPOINT   	Create a point to rollback to
START TRANSACTION;


UPDATE employee
SET salary = 50000
WHERE emp_id = 1;
COMMIT;


⭐ Interview Shortcut

DDL → Structure
DML → Data modification
DQL → Data retrieval
DCL → Permissions
TCL → Transactions

Remember:
CREATE, ALTER, DROP, TRUNCATE → DDL
INSERT, UPDATE, DELETE → DML
SELECT → DQL
GRANT, REVOKE → DCL
COMMIT, ROLLBACK, SAVEPOINT → TCL
