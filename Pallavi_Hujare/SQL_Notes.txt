SQL
SQL = Structured Query Language
SQL is used to communicate with and manage data stored in a relational database.
With SQL, we can:
Create databases
Create tables
Insert data
Read data
Update data
Delete data
Search/filter data


What is a Database
A database is an organized collection of data.

DBMS = Database Management System
A DBMS is software used to create, store, manage and retrieve data.
Examples:
PostgreSQL
MySQL
Oracle Database
Microsoft SQL Server
SQLite

RDBMS
RDBMS = Relational Database Management System
It stores data in the form of tables and allows relationships between tables

| Relational                           | Non-Relational                                          |
| ------------------------------------ | ------------------------------------------------------- |
| Data stored in tables                | Data can be documents, key-value, graphs, etc.          |
| Uses rows and columns                | Flexible structure                                      |
| Fixed/schema-based structure         | Usually more flexible schema                            |
| Uses SQL                             | Often uses database-specific query methods              |
| Primary & Foreign Keys commonly used | Relationships handled differently                       |
| Good for structured data             | Good for flexible/unstructured or rapidly changing data |
| MySQL, PostgreSQL, Oracle            | MongoDB, Redis, Cassandra                               |

# SQL Data Types
A data type defines what kind of value a column can store in a database.

1. Numeric Data Types

| Data Type      | Use                          | Example      |
| -------------- | ---------------------------- | ------------ |
| `INT`          | Whole numbers                | `25`         |
| `BIGINT`       | Very large whole numbers     | `9876543210` |
| `FLOAT`        | Decimal numbers              | `25.5`       |
| `DOUBLE`       | More precise decimal numbers | `25.5678`    |
| `DECIMAL(p,s)` | Exact decimal values         | `9999.99`    |

2. String / Character Data Types

| Data Type    | Use                  | Example                 |
| ------------ | -------------------- | ----------------------- |
| `CHAR(n)`    | Fixed-length text    | `'ABC'`                 |
| `VARCHAR(n)` | Variable-length text | `'Pallavi'`             |
| `TEXT`       | Large amount of text | `'Long description...'` |

3. Date and Time

| Data Type   | Use                                       | Example                 |
| ----------- | ----------------------------------------- | ----------------------- |
| `DATE`      | Date                                      | `'2026-08-11'`          |
| `TIME`      | Time                                      | `'14:30:00'`            |
| `DATETIME`  | Date + time                               | `'2026-08-11 14:30:00'` |
| `TIMESTAMP` | Date + time, commonly used for timestamps | `'2026-08-11 14:30:00'` |

4. Boolean
BOOLEAN stores a true/false value.
is_active BOOLEAN

Example:
INSERT INTO student
VALUES (1, 'Pallavi', TRUE);

SQL Operators – Notes

Operators are symbols or keywords used to perform operations or comparisons in SQL.

1. Arithmetic Operators

Used for mathematical calculations.

| Operator | Meaning             | Example     |
| -------- | ------------------- | ----------- |
| `+`      | Addition            | `marks + 5` |
| `-`      | Subtraction         | `marks - 5` |
| `*`      | Multiplication      | `fees * 2`  |
| `/`      | Division            | `fees / 2`  |
| `%`      | Modulus / remainder | `marks % 2` |

Example:
SELECT marks + 5 FROM student;
___________________________________

2. Comparison Operators
Used to compare two values.

| Operator | Meaning                  |
| -------- | ------------------------ |
| `=`      | Equal to                 |
| `<>`     | Not equal to             |
| `!=`     | Not equal to             |
| `>`      | Greater than             |
| `<`      | Less than                |
| `>=`     | Greater than or equal to |
| `<=`     | Less than or equal to    |


Examples:
SELECT * FROM student WHERE marks > 80;
SELECT * FROM student WHERE city = 'Pune';
SELECT * FROM student WHERE age >= 20;
SELECT * FROM student WHERE city <> 'Pune';
_________________________________________________________________________

3. Logical Operators
Used to combine or reverse conditions.

AND
Both conditions must be true.
SELECT * FROM student WHERE city = 'Pune' AND marks > 80;

OR
At least one condition must be true.
SELECT * FROM student WHERE city = 'Pune' OR city = 'Nashik';

NOT
Reverses the condition.
SELECT * FROM student WHERE NOT city = 'Pune';

4. Special Operators
BETWEEN
Checks whether a value is within a range.
SELECT * FROM student WHERE marks BETWEEN 60 AND 90;

IN
Checks whether a value matches any value in a list.
SELECT * FROM student WHERE city IN ('Pune','Nashik','Mumbai');

NOT IN
Excludes specified values.
SELECT * FROM student WHERE city NOT IN ('Pune','Nashik');

LIKE
Used for pattern matching.
SELECT * FROM student WHERE name LIKE 'R%';
R% → starts with R.

SELECT * FROM student WHERE name LIKE '%a';
%a → ends with a.

IS NULL
Checks for NULL values.
SELECT * FROM student WHERE city IS NULL;

IS NOT NULL
Checks for non-NULL values.
SELECT * FROM student WHERE city IS NOT NULL;

************************* Constraints ***********************

# Constraints are rules defined on columns in a database table to ensure data accuracy, validity, and integrity.
# The main constraints are PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE, DEFAULT, and CHECK.
| Constraint    | Purpose                               |
| ------------- | ------------------------------------- |
| `PRIMARY KEY` | Uniquely identifies each row          |
| `FOREIGN KEY` | Creates a relationship between tables |
| `NOT NULL`    | Prevents empty/NULL values            |
| `UNIQUE`      | Prevents duplicate values             |
| `DEFAULT`     | Provides a default value              |
| `CHECK`       | Restricts values based on a condition |

1. PRIMARY KEY
Uniquely identifies every record.id cannot be duplicate or NULL.

CREATE TABLE student (
    id INT PRIMARY KEY,
    name VARCHAR(30)
);

2. FOREIGN KEY
Connects one table to another table.Here, employee.d_id is the Foreign Key.

CREATE TABLE department (
    d_id INT PRIMARY KEY,
    d_name VARCHAR(30)
);

CREATE TABLE employee (
    e_id INT PRIMARY KEY,
    e_name VARCHAR(30),
    d_id INT,
    FOREIGN KEY (d_id) REFERENCES department(d_id)
);


3. NOT NULL
Does not allow NULL.

CREATE TABLE student (
    id INT PRIMARY KEY,
    name VARCHAR(30) NOT NULL
);

This is invalid:
INSERT INTO student VALUES (1, NULL);


4. UNIQUE
Does not allow duplicate values.Two students cannot have the same email.

CREATE TABLE student (
    id INT PRIMARY KEY,
    email VARCHAR(50) UNIQUE
);

5. DEFAULT
Automatically gives a value if you don't provide one.

CREATE TABLE employee (
    id INT PRIMARY KEY,
    name VARCHAR(30),
    city VARCHAR(20) DEFAULT 'Nashik'
);

If you insert:

INSERT INTO employee (id, name)
VALUES (1, 'Pallavi');

city automatically becomes:
Nashik


6. CHECK
Allows only values that satisfy a condition.

CREATE TABLE student (
    id INT PRIMARY KEY,
    name VARCHAR(30),
    age INT CHECK (age >= 18)
);

This is invalid:because age must be 18 or above.

INSERT INTO student
VALUES (1, 'Pallavi', 15);


****************  Referential integrity  *************************
Referential integrity
Definition
Referential integrity is a rule that ensures relationships between tables remain valid and consistent.
It means a Foreign Key value must either match an existing value in the referenced 
table or be NULL (if NULL is allowed).
Referential integrity prevents invalid or orphan records and keeps relationships between tables consistent.

Remember:
Primary Key → Parent table
Foreign Key → Child table
Referential Integrity → Keeps their relationship valid.

******** SQL Clauses *********
A clause is a part of an SQL query that performs a specific operation, such as filtering, grouping, or sorting data.

1. WHERE Clause
Used to filter rows based on a condition.

SELECT * FROM student WHERE city = 'Pune';

Other examples:

SELECT * FROM student WHERE marks > 80;
SELECT * FROM student WHERE age >= 20;
SELECT * FROM student WHERE city <> 'Pune';

Interview definition:
WHERE filters individual rows before grouping.
_______________________________________________________________________________________________________________________________
2. DISTINCT Clause
Used to return unique values and remove duplicates.

Syntax : SELECT DISTINCT column_name FROM table_name;
SELECT DISTINCT city FROM student;
________________________________________________________________________________________________________________________________
3. ORDER BY Clause
Used to sort the result.

Syntax : SELECT * FROM table_name ORDER BY column_name ASC;

Ascending
SELECT * FROM student ORDER BY marks ASC;

Descending
SELECT * FROM student ORDER BY marks DESC;

ASC = Ascending
DESC = Descending
_______________________________________________________________________________________________________________________________

4. GROUP BY Clause
Used to group rows having the same values.
Usually used with aggregate functions like COUNT(), SUM(), AVG(), MAX(), and MIN().

Syntax : SELECT column_name, COUNT(*)
FROM table_name
GROUP BY column_name;

SELECT city, COUNT(city)
FROM student
GROUP BY city;

Example:-
Pune     3
Nashik   2
Mumbai   1
