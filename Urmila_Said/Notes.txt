# SQL Data Types
A data type tells SQL what kind of data a column can store.

1.INT: Stores whole numbers.
For Ex:21,345 etc

2.TINYINT: TINYINT is used when you need to store small whole numbers.
For Ex:100

3.BIGINT: BIGINT is used for very large whole numbers.
For Ex:9876543210

4.DECIMAL: Stores decimal numbers.
For Ex: 87.40

5.FLOAT: Stores floating-point numbers.
For Ex: 12.3456

6.CHAR: Fixed-length text.
For Ex:'ABC'

7.VARCHAR: Variable-length text.
For Ex:'Urmila'

8.TEXT: Used for large amounts of text.
For Ex:Paragraph

9.DATE: Stores date.
Ex:.YYYY-MM-DD 

10.Boolean: Used for true/false values.
For Ex:True,False

11.BLOB: Store in Files,Aud,Vid,Img etc.


# Difference CHAR & VARCHAR.
| Feature            | `CHAR`                            | `VARCHAR`                                            |
| ------------------ | --------------------------------- | ---------------------------------------------------- |
| Full form          | Character                         | Variable Character                                   |
| Length             | Fixed                             | Variable                                             |
| Storage            | Always reserves defined length    | Uses space based on actual data                      |
| Example            | `CHAR(10)`                        | `VARCHAR(10)`                                        |
| If value is `"Hi"` | Stores as fixed-length value      | Stores only required characters + length information |
| Best for           | Fixed-length data                 | Variable-length data                                 |
| Examples           | Gender, country code, fixed codes | Name, email, address                                 |

#Operators
1. Arithmetic Operators
Used for mathematical calculations. 
| Operator | Meaning             | Example     |
| -------- | ------------------- | ----------- |
| `+`      | Addition            | `Marks + 5` |
| `-`      | Subtraction         | `Marks - 5` |
| `*`      | Multiplication      | `Marks * 2` |
| `/`      | Division            | `Marks / 2` |
| `%`      | Modulus / Remainder | `Marks % 2` |

EX:select Name Marks % 10 AS NewMarks
from Student;


2. Comparison Operators
Used to compare two values.
| Operator | Meaning               |
| -------- | --------------------- |
| `=`      | Equal to              |
| `<>`     | Not equal to          |
| `!=`     | Not equal to          |
| `>`      | Greater than          |
| `<`      | Less than             |
| `>=`     | Greater than or equal |
| `<=`     | Less than or equal    |

EX:select * from Student
where Marks = 80;

3. Logical Operators
Used to combine multiple conditions.

1.AND: Both conditions must be TRUE.
Query: select * from student1 where age > 18 and marks > 70;


2.OR :At least one condition must be TRUE.
Query: select * from student1 where city='Pune' or city='Mumbai';


3.NOT : Reverses the condition.
Query: select * from student1 where not city='Pune';


4.BETWEEN :Checks whether a value is within a range.
Query: select * from student1 where marks between 50 and 80;

# Constraints:
Constraints are rules applied to table columns to control what data can be inserted or stored in a database.

| Constraint    | Purpose                          |
| ------------- | -------------------------------- |
| `NOT NULL`    | Column cannot contain NULL       |
| `UNIQUE`      | Values must be unique            |
| `PRIMARY KEY` | Uniquely identifies each row     |
| `FOREIGN KEY` | Connects two tables              |
| `CHECK`       | Ensures a condition is satisfied |
| `DEFAULT`     | Provides a default value         |


1. NOT NULL: Prevents a column from having NULL values.
Synatx: CREATE TABLE Student (
      ID INT NOT NULL,
      Name VARCHAR(50) NOT NULL,
);

2. UNIQUE: Ensures that every value in a column is different.
Syntax:
CREATE TABLE Student (
    ID INT,
    Email VARCHAR(100) UNIQUE
);

3. PRIMARY KEY: Uniquely identifies each row AND Must contain unique values.
Syntax:
CREATE TABLE Student (
    ID INT PRIMARY KEY,
    Name VARCHAR(50)
);

4. FOREIGN KEY: A FOREIGN KEY creates a relationship between two tables.
Syntax:
CREATE TABLE Domain (
    D_ID INT PRIMARY KEY,
    D_Name VARCHAR(50)
);

* Domain table D_ID primary key use Intern table as a Foreign key

    CREATE TABLE Intern (
    I_ID INT PRIMARY KEY,
    Name VARCHAR(50),
    D_ID INT,
    FOREIGN KEY (D_ID) REFERENCES Domain(D_ID)
);


5. CHECK: Allows only values that satisfy a condition
Syntax:
CREATE TABLE Student (
    ID INT PRIMARY KEY,
    Name VARCHAR(50),
    Age INT CHECK (Age >= 18)
);

6. DEFAULT: Automatically inserts a value when you don't provide one.
Syntax:
CREATE TABLE Student (
    ID INT PRIMARY KEY,
    Name VARCHAR(50),
    City VARCHAR(30) DEFAULT 'Pune'
);

# Referential integrity :
Referential integrity is a database rule that ensures every foreign key value refers to an existing primary key 
value in the parent table, thereby maintaining valid relationships between tables.
Referential integrity prevents invalid or orphan records and keeps relationships between tables consistent.

Remember:
Primary Key → Parent table
Foreign Key → Child table
Referential Integrity → Keeps their relationship valid.

# Clauses
SQL Clauses are keywords used with SQL statements to filter, group, sort, and limit data.

1. FROM Clause: Specifies which table you want to retrieve data from.
Syntax: SELECT * FROM Student;

2. WHERE Clause: Used to filter rows according to a condition.
Syntax: SELECT * FROM Student WHERE Marks > 80;
using AND: SELECT * FROM Student WHERE Marks > 70 AND City = 'Pune';

3. DISTINCT Clause: Used to return unique values and remove duplicates.
Syntax : SELECT DISTINCT column_name FROM table_name;
EX : SELECT DISTINCT city FROM student;

4.ORDER BY Clause :Used to sort the result.
Syntax: SELECT * FROM Table_Name ORDER BY Col_Name ASC;

Ascending :ASC = smallest → largest.
Syntax: SELECT * FROM Table_Name ORDER BY Col_Name ASC;

Descending : DESC = largest → smallest.
Syntax: SELECT * FROM Table_Name ORDER BY Col_Name DESC;


5. GROUP BY Clause :Used to group rows having the same value.
Usually used with aggregate functions such as:

Syntax:SELECT column_name, aggregate_function(column_name)
FROM table_name
GROUP BY column_name;

* aggregate_function:
COUNT()
SUM()
AVG()
MAX()
MIN()

1:Count:
Syantax: SELECT Col_name, COUNT(*) AS New_col_name
FROM Table_Name
GROUP BY Col_Name;

Ex:SELECT City, COUNT(*) AS TotalStudents
FROM Student
GROUP BY City;

6.Having: Used to filter groups created by GROUP BY.
Syntax: SELECT column_name, aggregate_function(column_name)
FROM table_name
GROUP BY column_name
HAVING condition;

Ex:SELECT Gender, COUNT(*)
FROM Patient
GROUP BY Gender
HAVING COUNT(*) > 2;

# Important:
WHERE → filters individual rows
HAVING → filters groups

7.Limit :Used to restrict the number of records returned.
Syntax: SELECT *
FROM table_name
LIMIT number;

Ex: SELECT * FROM Patient
LIMIT 5;

8.OFFSET: Used to skip a specific number of records & Print the next records.
Syntax: SELECT *
FROM table_name
LIMIT number OFFSET number;

Ex: SELECT * FROM Patient
LIMIT 5 OFFSET 2;

9.Between: Used to find values within a range, including the boundary values.
Syntax: SELECT *
FROM table_name
WHERE column_name BETWEEN value1 AND value2;

Ex: SELECT * FROM Patient
WHERE Age BETWEEN 18 AND 30;

10.In :Used to check whether a value matches any value in a given list.
Syntax: SELECT *
FROM table_name
WHERE column_name IN (value1, value2, value3);

Ex: SELECT * FROM Patient
WHERE Gender IN ('M', 'F');

11.Like :Used for pattern matching.
     1: If % is on the right side it prints the words that start with the given letter.
     2: If % is on the left side it prints the words that end with the given letter.

Syntax: SELECT *
FROM table_name
WHERE column_name LIKE 'pattern';

Ex: Starts with U:
SELECT * FROM Patient
WHERE Name LIKE 'U%';

Ex: Ends with a:
SELECT * FROM Patient
WHERE Name LIKE '%a';

12. Update :The UPDATE statement is used to modify existing records in a table.
Syntax : UPDATE table_name
SET column_name = new_value
WHERE condition;

   1.One Column:
Ex : UPDATE Patient
SET Name = 'Pallavi Kapale'
WHERE ID = 6;

  2. Multiple coloumn :
Ex: UPDATE Patient
SET Name = 'Pallavi Kapale',
    Age = 22
WHERE ID = 6;

# Important
Always use WHERE when you want to update a specific record.

13. DELETE: The DELETE statement is used to remove existing records from a table.
Syntax : DELETE FROM table_name
WHERE condition;

Delete one record
Ex: DELETE FROM Patient
WHERE ID = 6;

Delete records based on a condition
EX: DELETE FROM Patient
WHERE Age < 18;

# Important
If you don't use WHERE: DELETE FROM Patient;
It will delete all records from the table. The table structure will still exist.

# Join in SQL

* Join: JOIN in SQL is used to combine rows from two or more tables based on a related column between them.
For example, suppose we have created two tables:
1) table department
2) table employee

d_id	d_name
1	   Computer
2	   Electrical
3	   Mechanical

employee
e_id	e_name	salary	  d_id
101	   Rahul	30000	   1
102	   Priya	35000	   2
103	   Amit	    28000	   1

Here, d_id is the common/related column.

---------------------------------------------------------------------------------------------------------------

1. Inner Join: INNER JOIN returns only the matching records from both tables.

Syntax:
SELECT columns
FROM table1
INNER JOIN table2
ON table1.column = table2.column;

EX: select employee.emp_id,employee.emp_name,employee.salary,employee.d_id
    from employee
    inner join department
    on department.d_id = employee.d_id;

-----------------------------------------------------------------------------------------------------------------

2. Right Join: RIGHT JOIN returns all records from the RIGHT table and matching records from the LEFT table.

Syntax:
SELECT columns
FROM table1
RIGHT JOIN table2
ON table1.column = table2.column;

EX: select employee.emp_id,employee.emp_name,employee.salary,employee.d_id
    from employee
    Right Join department
    on department.d_id = employee.d_id;

------------------------------------------------------------------------------------------------------------------

3.Left Join: LEFT JOIN returns all records from the left table and matching records from the right table.
             If there is no match, SQL returns NULL.

Syntax:
SELECT columns
FROM table1
LEFT JOIN table2
ON table1.column = table2.column;

Ex: select employee.emp_id,employee.emp_name,employee.salary,employee.d_id
    from employee
    Left Join department
    on department.d_id = employee.d_id;

-------------------------------------------------------------------------------------------------------------------

4. Full Outer Join: FULL OUTER JOIN returns all records from both tables.
It includes:
Matching records
Unmatched records from the left table
Unmatched records from the right table

Syntax: SELECT columns
FROM table1
FULL OUTER JOIN table2
ON table1.column = table2.column;

#Important :
MySQL does not directly support FULL OUTER JOIN.
We can achieve it using LEFT JOIN + UNION + RIGHT JOIN.

FULL OUTER JOIN = Everything from both tables

Syntax:
SELECT columns
FROM table1
LEFT JOIN table2
ON table1.column = table2.column;
UNION
SELECT columns
FROM table1
RIGHT JOIN table2
ON table1.column = table2.column;

EX: select employee.emp_id,employee.emp_name,employee.salary,employee.d_id
    from employee
    Left Join department
    on department.d_id = employee.d_id;
    UNION
    select employee.emp_id,employee.emp_name,employee.salary,employee.d_id
    from employee
    Right Join department
    on department.d_id = employee.d_id;

# VIEW : A VIEW is a virtual table created from one or more existing tables.
It does not normally store the actual data separately. Instead, it stores a SQL query, and whenever we use the view, SQL gets the required data from the original table.

Syntax :
CREATE VIEW view_name AS
SELECT column1, column2
FROM table_name;

EX: CREATE VIEW Pune_Interns AS
SELECT ID, Name, Domain
FROM Interns
WHERE City = 'Pune';

# INDEX 
An INDEX is a database object that helps SQL find data faster.
"An INDEX is a database object or data structure that improves the speed of data retrieval. It is mainly useful for 
frequently searched or joined columns, but indexes require additional storage and can slow down INSERT, UPDATE, and 
DELETE operations."

For EX: Think about a book.
If you want to find the topic "SQL JOIN" in a 500-page book:
Without an index → you may need to check many pages one by one.
With an index → you can directly find the page number.

*SQL INDEX works in a similar way.
INDEX = A structure that helps the database find rows quickly.

Syntax: CREATE INDEX index_name
ON table_name(column_name);

EX:CREATE INDEX idx_intern_name
ON Interns(Name);

Now searches using name can be faster:
SELECT *
FROM Interns
WHERE name = 'Urmila';

* Remove an index in MySQL:
DROP INDEX idx_interns_name ON Interns;


# Easy way to remember:
VIEW → Makes queries/data access easier
INDEX → Makes data searching faster

# DROP
It is used to completely remove a database object from the database.

1.Drop table:
Syntax: DROP TABLE table_name;
EX: DROP TABLE Interns;

* When you drop a table the table structure and its data are removed


2.Drop Database:
Syntax: DROP DATABASE database_name;
EX: DROP DATABASE InternshipDB;

* Very dangerous command because the database and its contents are removed.

3.Drop View:
Syntax: DROP VIEW Pune_Interns;

4.Drop index:
Syntax :DROP INDEX idx_city
ON Interns;


# DROP & DELETE Difference
| DELETE            | DROP                 |
| ----------------- | -------------------- |
| Removes rows      | Removes entire table |
| Table remains     | Table is removed     |
| Structure remains | Structure is removed |
| Can use `WHERE`   | No `WHERE`           |
| DML command       | DDL command          |


Easy trick:
DELETE → Data
DROP → Everything

# TRUNCATE 
TRUNCATE is a DDL (Data Definition Language) command used to remove all rows from a table at once.
TRUNCATE removes all data, but keeps the table structure.

Syntax: TRUNCATE TABLE table_name;
EX: TRUNCATE TABLE Interns;

* Easy

ALTER     → Change structure
RENAME    → Change name
TRUNCATE  → Remove all rows
DELETE    → Remove selected rows
DROP      → Remove complete table
