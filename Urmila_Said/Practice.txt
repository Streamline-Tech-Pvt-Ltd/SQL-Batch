1.Create Table:
Syntax:
 mysql> create table Patient(
    -> Id int,
    -> Name varchar(20),
    -> Age int,
    -> City varchar(10),
    -> Gender char(1),
    -> Appoimentdate date,
    -> Appoimentyear year,
    -> Isadmitted boolean,
    -> Bill decimal(5,5));

* Constraint And Data Types Use:
mysql> create table Patient(
    -> Id int primary key,
    -> Name varchar(20) not null,

    -> City varchar(10),
